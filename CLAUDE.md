# Start here

Before doing anything, read these two — they let you resume exactly where the last session
left off:

- **@PROJECT_LOG.md** — the project record: what exists, decisions, per-phase status, contract.
- **@SESSION_HANDOFF.md** — local, gitignored operational notes: exact build/commit/deploy
  commands, auth state, the reference-doc workflow, known TODOs. (On a fresh clone this file
  won't exist — that's expected; it's machine-local.)

Keep both updated as work progresses.
